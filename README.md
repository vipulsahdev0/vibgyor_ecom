# Vibgyor E-Commerce Platform

A full-stack E-Commerce application built using React, Spring Boot, JWT Authentication, and MySQL.

## Features

### User Features

* User Registration & Login
* Product Browsing
* Category Filtering
* Shopping Cart
* Wishlist Management
* Address Management
* Order Placement
* Order History

### Admin Features

* Dashboard Overview
* Category Management
* Product Management
* User Management
* Order Monitoring

## Setup Instructions

### Backend

1. Clone Repository

```bash
git clone https://github.com/vipulsahdev0/vibgyor_ecom.git
```

2. Configure MySQL

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/vibgyor_ecom
spring.datasource.username=root
spring.datasource.password=root
```

3. Run Backend

```bash
mvn spring-boot:run
```

Backend URL:

```text
http://localhost:8080
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```
